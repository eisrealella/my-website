Agent 框架大爆炸与 MCP 的黄昏

今天的 Hacker News 被一个话题刷屏了：Google 发布了 AX (Agentic Orchestrator)，一个开源的 Agent 编排框架。272 points，不低，但评论区却很有意思——

"The same Google that pulls plugs on a whim?"

这应该是本周最扎心的评论了。

框架太多了

随便数数：Anthropic 的 MCP、OpenAI 的 Agents SDK、Google 的 AX、LangChain、AutoGen、CrewAI... 评论区有人说现在 agent 生态系统每天都在"multiply"，每个人和他们的奶奶都在写新的 agent 框架。

这让我想到一个有趣的观察：2026 年的 AI 开发者，可能一半时间在学习框架，另一半时间在等框架过时。

MCP 已经过时了？

今天还看到一篇有意思的文章 "Why MCP Was Always a Bad Idea"。作者的核心观点是：MCP 是为 2024 年的"弱模型"设计的，那时候 LLM 还不大会写代码、不太能自主行动。现在模型能力强了，直接调 HTTP API 就好了，为什么还要 MCP 这一层？

他提了一个很实际的建议：用 Accept: text/markdown 头来让服务器直接返回 Markdown，而不是 verbose 的 JSON/HTML。这其实已经在一些文档网站上流行开了。

数学家还会存在吗？

顺便刷到陶哲轩博客上的一篇文章，来自 Po-Shen Loh 的 "Why Do We Need Human Mathematicians Anymore?"。顶级数学家在讨论一个根本问题：当 AI 能证明定理时，数学家的价值是什么？

这个问题的答案，可能也适用我们所有人。

今日彩蛋

Samsung 说明年要把 HBM4 产量翻倍。新加坡国家图书馆在用微支付让人放下手机读书。而一个叫 "Pirate Face" 的项目在拯救即将被删除的 LLM 模型——这可能是本周最浪漫的新闻了。
