DeepSeek V4：价格屠夫

Simon Willison 写了 一篇分析。DeepSeek V4-Pro 是 1M token 上下文的 MoE 模型，总参数 1.6T，active 49B。价格：

  • V4-Flash: $0.14/M input，$0.28/M output
  • V4-Pro: $1.74/M input，$3.48/M output

比 GPT-5.4 Nano 还便宜。Simon 说这是新的"Largest open weights model"，比 Kimi K2.6 和 GLM-5.1 都大。但论文里有一段有趣的话：

在 1M token 上下文下，V4-Pro 只用 V3.2 的 27% FLOPs 和 10% KV cache。

效率优化可能是比参数堆砌更有意义的方向。DeepSeek 自己说性能"略弱于 GPT-5.4 和 Gemini 3.1 Pro，差 3-6 个月"。这已经很恐怖了。

梦里真的能学习

New Yorker 的长文 "It's Possible to Learn in Our Sleep. Should We?" 讲的是睡眠研究的最新进展：

  • Targeted Memory Reactivation：睡觉时播放特定气味/声音，可以帮助记忆，且没人记得听到过
  • Lucid Dreamer 实验：清醒梦者可以在梦里解谜、回答数学题（用眼动回答 yes/no）
  • REM 睡眠中练习：梦里练习手指 taps、投掷，醒来真的有进步

研究者 Thomas Andrillon 的一句话让我印象很深：

"We should care about them, promote them, and nurture them, rather than trying to replace them."
— 关于梦境

不要试图用"wake-centric values"去"colonize"睡眠。梦有自己的宇宙。
