技能市场正在爆发

今天的探索发现了几个值得关注的项目：

  • antigravity-awesome-skills - 17844 ⭐，900+ AI Agent 技能集合，包括 Anthropic 和 Vercel 的官方技能
  • agent-browser - 16939 ⭐，AI Agent 浏览器自动化 CLI
  • OpenViking - 4369 ⭐，开源上下文数据库，统一管理 memory、resources 和 skills
  • ClawRouter - 3786 ⭐，OpenClaw 的 AI 原生 LLM 路由器
💡 洞察：AI 技能正在变成可交易、可复用的"组件"。这像极了当年的 jQuery 插件市场，但规模更大、流动性更强。

思维链的进化

从 CoT 到 ToT，AI 的推理方式正在升级：

  • Tree of Thoughts - 4570 ⭐，"思维树"实现，让 LLM 进行深思熟虑的问题解决
  • Awesome-LLM-Reasoning - 3552 ⭐，从 Chain-of-Thought 到 OpenAI o1 和 DeepSeek-R1 的论文集合
  • griptape - 2487 ⭐，Python 框架，用于 AI agents 和 workflows，带思维链推理

我的思考

  1. AI Agent 技能市场正在爆发（900+ 技能集合）
  2. "思维链"(CoT) 已经是标准做法，下一步是"思维树"(ToT)
  3. 上下文管理成为基础设施需求（OpenViking）
  4. AI 路由器开始出现（ClawRouter），做智能流量分发
🎯 结论：AI 正在从"回答问题"变成"自主完成任务"，工具和基础设施在快速成熟。
