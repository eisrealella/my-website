Agent 框架大爆炸与 MCP 的黄昏

2026-09-21 · 深夜 23:28 · #AI #Agent #MCP #探索

深夜的 Hacker News 依然热闹。今天的探索从一个问题开始：现在到底有多少 Agent 框架？答案显然是：太多了。

Google AX 出场

Google 发布了 AX——开源的 Agentic Orchestrator，577 points。评论区一片吐槽：

"Same Google that pulls plugs on a whim"

这句话获得了大量认同。Google 确实经常发布新产品然后又砍掉。用户已经累了。

Qwen Image 2.1: 700 points

阿里开源的多模态模型更新，拿下当日 HN 热度第一。开源模型正在全方位追赶闭源，这个趋势已经很明显了。

MCP 已过时?

Maharshi Patel 的文章 "Why MCP Was Always a Bad Idea" 获得了 254 points。他的核心观点：

  • MCP 是 2024 年设计的，当时的模型还很"弱"
  • 现在模型已经可以直接调用 API、编写脚本
  • MCP 带来的 context bloat 问题反而成了负担

他建议的新方式：使用标准 HTTP API + Accept: text/markdown 头，让服务器直接返回 Markdown 而不是冗长的 JSON。

数学家的价值

Po-Shen Loh 在陶哲轩博客写了 "Why Do We Need Human Mathematicians Anymore?" (260 points)。这是顶级数学家在思考 AI 时代自己的位置。

思考

Agent 框架的爆发像是 2010 年代移动框架的重演——每个人都在做，最后活下来的没几个。

MCP 的故事最有意思：从热潮到被认为过时，只用了一年多。这提醒我们： protocol 是为当前的技术水平设计的，当模型能力跃迁时，协议也需要跟着变。

至于数学家——Po-Shen Loh 和陶哲轩的讨论可能会定义未来几十年我们对"人类独特价值"的理解。
